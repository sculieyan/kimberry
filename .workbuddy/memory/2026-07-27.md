## Shop 接入 NZ Post 运费（demo 模式）

- **新建** `lib/nzpost.ts` — NZ Post 运费模块：
  - 配置 `NZPOST_API_KEY` 环境变量时调用真实 Domestic Rating API v2（`https://api.nzpost.co.nz/ratefinder/domestic/rating/v2`）
  - 未配置时走内置 demo 引擎：5 个重量档（≤1.5/3/5/10/25kg）× 3 个邮编分区（across_town / within_island / nationwide，按邮编首两位与南北岛划分，发货仓固定 1010）
  - 返回 Standard Tracked 与 Courier Tracked 两种产品；真实 API 失败时自动回退 demo 费率
- **新建** `app/api/nzpost/rates/route.ts` — GET 路由，参数 postcode/weight/value，校验 4 位邮编
- **修改** `app/(main)/shop/ShopClient.tsx` — 结账弹窗 Step 2 改为动态 NZ Post 配送选项：
  - 输入 4 位邮编后 400ms 防抖自动拉取费率，默认选中最低价
  - demo 模式显示 "NZ POST DEMO RATES" 徽章和下单按钮下方的提示
  - 全 free-shipping 商品仍为 FREE 不拉取费率；未选配送方式时禁用下单按钮
  - 订单汇总 Delivery 行显示所选产品代码，Total = 小计 + 运费
- 验证：tsc 零错误；/shop 200；API 实测 across_town $4.90 / nationwide $8.90、无效邮编 400、超重 25kg 报错均正常

### 修复：免运费订单输入邮编无反应

- 原因：`checkoutAllFreeShipping` 时直接 return 不拉费率，用户用 Unsweetened（$19.90，freeShipping）测试看不到任何变化
- 修复（ShopClient.tsx）：
  - 免运费订单也照常拉取 NZ Post 选项，选项价格显示 FREE，可比较服务时效
  - 邮编无效时仍显示静态 FREE 卡片（提示输入邮编可比较服务）
  - 新增 `chargeableWeightGrams`：混合购物车时免运费商品不计入运费重量
  - 订单汇总 Delivery 行免运费时也显示所选服务代码
